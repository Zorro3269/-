1. 温湿度传感器DHT11：构建微气候底座
怎么使用： 通常部署在做青机内部或做青间的高低不同位置，实时采集环境数据。

核心作用（看天做青）： 岩茶的“走水”（水分从叶脉输送到叶缘散失）和多酚类物质的酶促氧化，对温湿度极度敏感。

温度： 控制酶的活性。温度过高容易“死青”，过低则发酵停止。

湿度： 控制水分散失速率。通过单片机读取温湿度数据，系统可以自动决策是否需要开启排风扇、加热器或加湿器，将微气候稳定在最适宜的区间（例如 22-25℃，湿度 70-80%）。

2. 二氧化碳有机物气体传感器SGP30：量化“茶香”：监测呼吸强度
怎么使用： 安装在做青滚筒或密闭静置槽的排气口附近。

核心作用： 茶叶在采摘后依然是“活”的，在摇青和静置过程中会进行剧烈的呼吸作用，消耗氧气并释放二氧化碳。

当 CO₂ 浓度快速上升，说明叶片细胞活性高，发酵剧烈。

如果 CO₂ 浓度超标，说明环境缺氧，茶叶容易“闷青”（产生异味）。此时 STM32 会根据设定的阈值，自动触发新风系统或排风扇进行换气。


怎么使用： 同样部署在空气流通处，专门捕捉挥发性有机化合物。

核心作用（闻香做青）： 岩茶在做青时，气味会发生奇妙的转变——从最初的“青草气”，慢慢转化为“清花香”，最后是深沉的“果香”。

TVOC 传感器可以检测到醇类、醛类等芳香物质的浓度变化曲线。

当代表特定花果香的有机物浓度达到峰值时，系统可以记录这一特征节点，辅助判断做青是否应该进入下一个阶段（如杀青），防止发酵过度或不足。

3. OpenMV (机器视觉)：替代老茶师的“眼睛”
怎么使用： 摄像头固定在做青摊叶架上方，或者做青机出口，配合光源（消除阴影），定时对茶叶进行拍照和图像处理。

核心作用（看青做青）： 传统做青讲究看茶叶的外观变化，OpenMV 在这里大显身手：

色块追踪与阈值分割： 岩茶做青最标志性的变化是“绿叶红镶边”（叶片边缘由于碰撞氧化变红，中心保持绿色）。OpenMV 可以提取图像的 LAB 或 HSV 颜色模型，计算红色像素与绿色像素的比例。

形态学分析： 监控叶片的萎凋萎缩程度（边缘卷曲度）。

当红绿比例达到老茶师认可的标准阈值时，OpenMV 通过串口将信号发给主控，主控便知道“摇青到位了”。
